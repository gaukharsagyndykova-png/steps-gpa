# Steps and Academic Performance

Streamlit app for a Mathematical Statistics course project: do daily steps affect students' GPA?

- `app.py` — the app (10 sections, sidebar navigation)
- `data/survey_responses.csv` — all 60 survey answers; column `Group` marks the cleaning result (`ok` = analysed)
- `data/powerbi_dashboard.png`, `data/google_form.png` — screenshots shown in the app

Run locally:

```
pip install -r requirements.txt
streamlit run app.py
```
